# 倒带音乐 · 无损音乐整理与试听

> 把散落在各处的曲目信息、歌词和整轨资源归拢到一个页面里 —— 不用在十几个站点之间来回跳。

**站点地址：<https://daomp3.com/>**

---

## 这是什么

一个安静的音乐资料站。每首歌一个页面，放这几样东西：

| 内容 | 说明 |
| --- | --- |
| 在线试听 | 打开就能听，不用注册、不装客户端 |
| 逐行歌词 | 和音频对时，可单独下载 LRC |
| 文件详情 | 格式、体积、平均码率写清楚 |
| 下载入口 | 高品质 MP3 与无损 FLAC / WAV，指向第三方网盘公开分享 |
| 同专辑 / 同歌手 | 顺着专辑脉络或歌手作品往下听 |

本站**不存储任何音频文件**，只汇总第三方网盘的公开分享链接。曲目信息与歌词仅用于介绍与检索。

## 为什么做这个站

找一首老歌的无损版本，通常要经历：搜索结果里点开五六个页面 → 每个页面都在诱导装下载器 → 装完发现是 128k 的 MP3。

所以这里只做三件事：

1. **信息准确**：格式、体积、码率都按实际文件写，不把有损改名成无损。
2. **页面干净**：没有弹窗、没有强制登录、没有下载器。
3. **结构清晰**：一首歌一页，专辑和歌手都能顺下去听。

## 技术栈

- Node.js + SQLite，服务端渲染（SSR），无前端框架运行时
- 页面 TTFB 约 0.2 秒
- 结构化数据：MusicRecording / MusicAlbum / MusicGroup / BreadcrumbList / AudioObject
- sitemap 分片提交，RSS 同步更新
